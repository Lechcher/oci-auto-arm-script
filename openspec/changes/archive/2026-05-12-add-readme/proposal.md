## Why

The project lacks a README file. A clear entry point is needed to explain what the script does, how to use it, its authentication mechanisms, and artifact handling features so users can adopt it easily.

## What Changes

- Add a top-level `README.md` file.
- Document script purpose, prerequisites, and basic usage.
- Document default launch behavior vs raw command mode.
- Document OCI CLI bootstrap mechanism.
- Document authentication methods (API key, instance principal, resource principal).
- Document project-local run artifact output.

## Capabilities

### New Capabilities
- `documentation`: Centralized documentation covering usage, authentication, and artifact behaviors.

### Modified Capabilities
None.

## Impact

- Adds `README.md` to repository root.
- No code or runtime impact.
